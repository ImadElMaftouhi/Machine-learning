# Machine Learning & AI

A personal workspace for exploring, learning, and experimenting with Machine Learning and Artificial Intelligence topics, from core fundamentals to cutting-edge research.

## Repository Structure

```
Machine-learning/
├── fundamentals/              # Core libraries and data science basics
│   ├── numpy/                 # Array computing and numerical operations
│   ├── pandas/                # Data manipulation and analysis
│   ├── matplotlib/            # Data visualization
│   └── scipy/                 # Scientific computing
│
├── classical_ml/              # Traditional Machine Learning algorithms
│   ├── regression/            # Linear, polynomial, ridge, lasso...
│   ├── classification/        # SVM, KNN, decision trees, random forests...
│   ├── clustering/            # K-Means, DBSCAN, hierarchical...
│   └── dimensionality_reduction/  # PCA, t-SNE, UMAP...
│
├── deep_learning/             # Neural Network architectures
│   ├── neural_networks/       # Feedforward networks, MLPs
│   ├── CNNs/                  # Convolutional Neural Networks
│   ├── RNNs_LSTMs/            # Recurrent networks, sequence modeling
│   ├── transformers/          # Attention mechanisms, BERT, GPT...
│   └── GNNs/                  # Graph Neural Networks
│
├── nlp/                       # Natural Language Processing
├── computer_vision/           # Image and video understanding
├── reinforcement_learning/    # RL algorithms and environments
│
├── datasets/                  # Raw and processed datasets
├── notebooks/                 # Exploratory and experimental notebooks
├── scripts/                   # Reusable utility scripts
├── projects/                  # End-to-end ML projects
├── utils/                     # Shared helper functions and tools
│
└── requirements.txt           # Python dependencies
```

## Tech Stack

| Category        | Libraries                                      |
|-----------------|------------------------------------------------|
| Core            | NumPy, Pandas, SciPy, Matplotlib, Seaborn      |
| Classical ML    | Scikit-learn                                   |
| Deep Learning   | PyTorch, TensorFlow                            |
| NLP             | Transformers (HuggingFace)                     |
| Visualization   | Matplotlib, Seaborn, Plotly                    |
| Environment     | Jupyter, IPython                               |

## Getting Started

```bash
# 1. Clone the repository
git clone <repo-url>
cd Machine-learning

# 2. Install dependencies
pip install -r requirements.txt

# 3. Launch Jupyter
jupyter notebook
```
